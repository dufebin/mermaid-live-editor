# Single-Binary Production Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the compiled frontend (`docs/`) and the storage API from the single Go binary, replacing the `pnpm dev` production unit.

**Architecture:** A `staticHandler` wrapper in the Go server mounts a static directory (env `STATIC_DIR`, empty = API-only, current behavior) in front of the API mux on the same port: `/api/*` and non-GET fall through to the mux, files are served by `http.FileServer`, everything else gets the adapter-static SPA fallback `404.html` with status 200. The `mermaid-frontend` systemd unit switches from `pnpm dev` to the Go binary on 0.0.0.0:3000; a `build:prod` npm script produces both artifacts.

**Tech Stack:** Go 1.26 stdlib (`net/http`, `os`, `path/filepath`), pnpm, systemd.

**Spec:** `specs/2026-11-11-single-binary-deploy-design.md`

## Global Constraints

- `STATIC_DIR` default empty = API-only (dev workflow unchanged: vite dev on :3000 proxying `/api` to the storage server).
- Production: `HOST=0.0.0.0 PORT=3000 STATIC_DIR=docs` on the `mermaid-frontend` unit; `mermaid-storage` (18790) must be STOPPED while production runs (two writers on one SQLite file).
- `/api/*` never intercepted by static serving; unknown `/api` paths keep the mux's `404 {"error":"Not found"}` JSON.
- Directory listing disabled; unknown directories fall to the SPA fallback.
- No new Go dependencies. Svelte 5 runes; ESLint sort-keys; `docs/` is build output (generated by `pnpm build`, never hand-edited).
- Working tree has unrelated uncommitted user WIP — stage only files this plan names; never repo-wide `pnpm lint:fix`.
- Every commit message ends with `Co-Authored-By: Claude Code <noreply@anthropic.com>`.

	rec = httptest.NewRecorder()

	rec = httptest.NewRecorder()
	h.ServeHTTP(rec, httptest.NewRequest("POST", "/edit", nil))

- [ ] **Step 3: Implement `server-go/static.go`**

```go
package main

import (
	"net/http"
	"os"
	"path/filepath"
	"strings"
)

// staticHandler serves dir on the same port as the API. /api/* (and any
// non-GET/HEAD request) falls through to the API mux; existing files are
// served statically; everything else gets the adapter-static SPA fallback
// (404.html) with status 200 so client-side routing takes over.
func staticHandler(dir string, api http.Handler) http.Handler {
	files := http.FileServer(http.Dir(dir))
	fallback := filepath.Join(dir, "404.html")
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if strings.HasPrefix(r.URL.Path, "/api/") || r.URL.Path == "/api" ||
			(r.Method != http.MethodGet && r.Method != http.MethodHead) {
			api.ServeHTTP(w, r)
			return
		}
		// filepath.Clean("/"+path) stays inside dir; ServeFile also rejects
		// traversal. Directories fall through to the fallback (no listing).
		target := filepath.Join(dir, filepath.Clean("/"+r.URL.Path))
		if info, err := os.Stat(target); err == nil && !info.IsDir() {
			files.ServeHTTP(w, r)
			return
		}
		http.ServeFile(w, r, fallback)
	})
}

func staticDirOrNone(dir string) string {
	if dir == "" {
		return "off"
	}
	return dir
}
```
